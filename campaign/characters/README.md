# Characters

One Markdown file per player character, same rules as a session script:
`#` for the character's name, `##` for sections, `>` for anything you want
in italics with a border (a voice line, a read-aloud introduction), bullets
for facts. The build compiles them into the plugin; the Script tab shows
them under Characters, with Insert on this page and Insert as new pages.

Good sections: At a glance, Hooks, Wants, Secrets (DM only), Table notes.
Anything marked (check) was inferred from the session scripts and should be
confirmed against the actual character sheet.
